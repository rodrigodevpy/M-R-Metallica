# M&R Metalúrgica

Site institucional em HTML, CSS e JavaScript puros (sem build, sem dependências).

## Como abrir
Abra `index.html` no navegador.

## Como publicar (GitHub Pages)
1. Envie os arquivos para a raiz de um repositório.
2. Em **Settings > Pages**, escolha a branch `main` e a pasta `/ (root)`.

## Como editar
- WhatsApp: altere `WHATSAPP` e `WA_DISPLAY` no topo de `script.js`, e os links `wa.me` em `index.html`.
- Números da faixa laranja (obras, anos, empresas): valores de exemplo em `index.html`, atributos `data-count`.
- E-mail, endereço e horário: seção de contato e rodapé em `index.html`.
